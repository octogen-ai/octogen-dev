# API Documentation

Store API schemas, endpoint notes, generated references, and compatibility guidance for SDK authors.

- [Platform Catalog API v1 — Reference](./platform-catalog-api-v1.md): REST
  endpoints for listing catalogs and searching/looking up products with a
  Platform API key. Mirrors the
  [Catalog Partner MCP](../guides/catalog-partner-mcp.md) tools.
- [Coverage URL Lists API v1 — Reference](./coverage-url-lists-v1.md): REST
  endpoints for uploading named sets of product URLs that Octogen joins
  against its crawled catalogs daily and shares back as per-list BigQuery
  listings.
